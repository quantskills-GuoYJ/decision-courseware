Lesson 0 · Decision Models

第0课：决策模型是什么

一句话：决策模型把非结构化状态 + 调用方钉死的选项问题，一次前向映射成已校准的选项概率——不是让 LLM「吐一段像概率的话」。

⚠ 先钉死这个盲点
吐了个像概率的答案 ≠ 决策模型。真正的决策模型硬性要求三件事：选项钉死、校准概率、可设门槛。
Section 02

生成式 LLM vs 决策模型

一个擅长开放生成；一个专门回答「在钉死的选项里，各有多大把握？」

生成式 LLM

  • 自回归逐 token 生成开放文本
  • 选项空间不固定——可编造任何说法
  • 「概率」常是口头数字，未必校准
  • 适合：写作、检索摘要、开放推理
  • 不适合：需要拒答门槛的交易决策

决策模型

  • 非自回归：一次前向 → 选项概率
  • 选项空间钉死（caller-defined）
  • 输出是已校准的概率分布
  • 原语：choice / score / noul
  • 适合：平仓与否、风控闸门、Agent 执行门
① 选项钉死 ② 校准概率 ③ 可设门槛
Section 03

一次前向：状态 → 校准概率

非结构化状态 + 类型化问题 → 单次 forward pass → choice / score / noul 概率。

输入：状态 + 类型化问题 输出：校准后的选项概率 原语 choice / score / noul

Section 05

校准长什么样

可靠性图（reliability）与 ECE / Brier：概率说 80%，真实命中也该接近 80%。

可靠性示意（理想 vs 未校准）

ECE

Expected Calibration Error：分桶后 |预测置信 − 实际准确率| 的加权平均。越小越好。

Brier Score

均方概率误差。同时惩罚「错得自信」与「对得含糊」。越小越好。

NLL · 后处理

负对数似然。常用 temperature scaling / isotonic；训练侧有 RLCD（Reinforcement Learning for Calibrated Decisions）。

概念参考：Laya · Calibrated Probabilities · RLCD —— 概率必须可解释为长期频率，才能放心设门槛。
LAYA SUPPORT SAMPLE · 90% GATE（研究摘录，未另造数）

Section 06

Agent 闸门：三态 + 双层

用 risk–coverage 门槛扫描，把决策压成三种执行态。点选卡片查看含义。

🟢

高 · 自动

置信过门槛，系统直接执行

🟡

中 · 复核

落在灰区，排队人工确认

🔴

低 · 人工

拒答或强制人工接管

两层闸门，别混为一谈

1
AutoThink · 模型内部门 模型侧是否继续深思 / 是否输出决策分布——StartLux AutoThink 的内部 gate。
2
App · 执行门 应用侧根据校准概率与业务风险，决定自动 / 复核 / 人工。与模型内部门分离。
