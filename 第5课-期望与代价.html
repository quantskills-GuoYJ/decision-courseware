期望效用：代价不对称时，一半不是门槛

目标：在写明的事件和收益下，算出自动的期望。不自动的收益是 0。数字是课堂假设，不是交易盈亏，也不是对所有代价都最优的规则。

先猜

事件：自动之后，这件事「做成」或「没做成」，二者只发生一个。做成的收益是 +1，没做成的收益是 −3。不自动的收益固定为 0，这是中性备选。现在 P(做成) = 0.55。自动的期望是 p×1 + (1−p)×(−3)。它是严格为正，还是低于 0？先心算，再提交。打平点留到揭晓：期望恰好为 0 的 p，还不是严格为正。本课平局规则与前面的 p ≥ θ 一致，恰好打平时仍自动。这只在这两种结果、这两种收益下成立。

提示：不要只看 0.55 和 0.5。把 (1−0.55) 乘上 3，再和 0.55×1 比。

不自动的收益是 0。0.55×1 + 0.45×(−3) = 0.55 − 1.35 = −0.80，低于中性备选。打平点 p* = 3/(1+3) = 0.75，这时期望等于 0，与不自动无差异，还不是严格为正。严格为正要 p > 0.75。本课平局规则：p ≥ p* 才自动，和前面课的 p ≥ θ 一样。恰好 0.75 时按这条规则自动，不是因为期望已经为正。这不是对所有代价都最优。

实验：改代价，看门槛跟着变

收益 B 固定为 +1，做错是 −C。不自动的收益保持为 0。拖动 C。打平点 p* = C / (1+C)，这是期望等于 0 的点。P 固定为 0.55。平局规则：p ≥ p* 自动；p > p* 时期望才严格为正。

代价变成 1 比 1

若做错的代价也是 1，P 仍是 0.55。按同一公式，期望是正的吗？

提示：代价都是 1 时，打平点是 0.50。0.55 比它高，期望严格为正。平局规则仍是 p ≥ p*。

代价变了，打平点就变了。「超过一半」只在收益和损失一样大时才是打平点。0.55×1 − 0.45×1 = 0.10，严格为正。这仍是这两种结果下的假设，不是对所有代价都最优，也不是市场报价。
